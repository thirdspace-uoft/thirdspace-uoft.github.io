## How to read this file

- ✅ = DOI/link individually verified via web search this session (correct as originally listed, or corrected)
- 🔧 = **Corrected** — the original DOI was wrong (see note)
- ⚠️ = **Not individually re-verified** in this pass — kept as in the original file. These are almost entirely ACM Digital Library proceedings DOIs (CHI/CSCW/FAccT/DIS/GROUP/COMPASS/ICTD, 2014–2025) that follow the correct, sequential per-conference numbering pattern ACM assigns, and a small verified sample from this range all checked out correct — but I did not click through all ~150 of them individually.
- ❓ = No real DOI could be found (common for pre-2015 regional/Bangladeshi conference papers and book chapters/theses predating routine DOI registration); a publisher/repository link is given instead where one exists.

**Important finding:** a cluster of entries — mostly 2008–2013 — had DOIs that were duplicated across completely unrelated papers (e.g. the same IEEE DOI reused for four different autism-related papers, and the same Springer chapter DOI reused for a 2010 journal article, a 2008 conference paper, and a Bachelor's thesis). These have been corrected or marked ❓ below.
